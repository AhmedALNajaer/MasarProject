# 🎓 Masar Platform (Frontend)

This project is the frontend interface for the **Masar** platform, built with React + Vite. It is designed to showcase educational tracks and training courses for IT college students.

---

## 🛠️ How to Run the Project

1. **Clone the repository:**

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-folder>
git checkout frontand


Install dependencies:
npm install

Start the development server:
npm run dev


Requirements:

Node.js ^18
npm ^9
